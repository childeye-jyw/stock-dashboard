# 📊 Stock Dashboard (주식 거래대금 분석)

어제 거래대금이 2,000억 이상인 종목을 필터링하고, 선택한 종목의 최근 3개월 거래대금 및 일봉 차트를 보여주는 Streamlit 대시보드입니다.

---

## ✨ 주요 기능

### 📈 거래대금 분석
- **어제 거래대금 상위 종목 필터링**: 설정 가능한 임계값(기본 2,000억 원) 이상의 거래대금을 기록한 종목 표시
- **최근 3개월간 거래대금 통계**: 각 종목의 임계값 이상 거래대금을 기록한 날짜 수 계산 및 표시
- **필터링 기능**: 최근 3개월간 거래대금이 임계값 이상이었던 날이 설정된 횟수(기본 5회) 이하인 종목만 표시

### 📊 시각화
- **거래대금 추이 그래프**: 선택한 종목의 최근 3개월간 거래대금 추이를 라인 차트로 표시
- **일봉 캔들스틱 차트**: 선택한 종목의 최근 3개월간 일봉 차트를 캔들스틱 형태로 표시

### ⚙️ 설정 옵션
- **거래대금 임계값 조정**: 사이드바에서 100억~10,000억 원 범위로 조정 가능
- **필터 조건 조정**: 최근 3개월간 거래대금 임계값 이상 날짜 수의 최대값 설정 (0 입력 시 필터링 없음)

### 🚀 성능 최적화
- **데이터 캐싱**: Streamlit 캐싱을 활용하여 반복 조회 시 성능 향상
  - 티커 매핑: 1시간 캐싱
  - 시장 데이터: 5분 캐싱
  - 종목 히스토리: 5분 캐싱

### 🌏 한국 시간대 지원
- **KST(UTC+9) 기준 날짜 계산**: Streamlit Cloud 배포 시에도 한국 시간 기준으로 "어제" 날짜 계산
- `zoneinfo` (Python 3.9+) 또는 `pytz` (fallback) 사용

## 🚀 실행 방법

### ▶️ 로컬에서 실행

```bash
# 패키지 설치
pip install -r requirements.txt

# 앱 실행
streamlit run app.py
# 또는
python3 -m streamlit run app.py
```

브라우저에서 `http://localhost:8501`로 접속하세요.

### ☁️ Streamlit Cloud 배포

이 프로젝트는 GitHub에 푸시하면 자동으로 Streamlit Cloud에 배포됩니다.

- **배포 URL**: https://childeye-stock-dashboard.streamlit.app/
- **자동 배포**: `main` 브랜치에 푸시 시 자동으로 배포됨

## 📋 요구사항

### Python 버전
- Python 3.9 이상 권장 (Python 3.8 이하에서는 `pytz` 패키지 필요)

### 필수 패키지
- `streamlit`: 웹 대시보드 프레임워크
- `pykrx`: 한국거래소 데이터 수집
- `plotly`: 인터랙티브 차트 생성
- `pandas`: 데이터 처리
- `pytz`: 시간대 지원 (Python 3.8 이하 또는 zoneinfo 미지원 환경)

## 🎯 사용 방법

1. **거래대금 임계값 설정**: 사이드바에서 원하는 거래대금 임계값을 설정합니다 (기본값: 2,000억 원)

2. **필터 조건 설정**: 최근 3개월간 거래대금이 임계값 이상이었던 날의 최대 횟수를 설정합니다 (기본값: 5회)

3. **종목 선택**: 필터링된 종목 목록에서 분석하고 싶은 종목을 선택합니다

4. **차트 확인**: 선택한 종목의 최근 3개월 거래대금 추이와 일봉 차트를 확인합니다

- **데이터 범위**: 최근 3개월간의 일봉 데이터
